# 深色控制台与品牌头部简化设计

## 目标

移除左上角蓝色“声”Logo，将整个本地配音工作台改造成固定的深色控制台界面，同时保持现有信息架构、交互行为和响应式布局不变。

## 方案选择

1. **固定深色控制台（采用）**：视觉稳定、无需维护主题切换状态，符合用户明确要求。
2. 明暗主题切换：灵活，但需要额外的持久化、闪烁防护和双主题回归，本次没有必要。
3. 跟随操作系统：实现简单，但最终外观不确定，不能保证始终是深色控制台。

## 品牌头部

- 从 HTML 中彻底删除 `.brand-mark` 和“声”字图标。
- 保留 `GPT-SoVITS × IndexTTS2` 与 `情绪配音工作台`，作为纯文字产品标识。
- 收紧标题区间距，让服务状态与全局刷新仍保持当前布局。

## 视觉语言

- 页面背景：接近黑色的冷色深蓝。
- 面板：使用两级深色表面区分主面板与嵌套区域，不依赖厚重阴影。
- 边框：低亮蓝灰色；选中与焦点使用清晰的亮蓝色。
- 文本：主文字使用高对比冷白，说明文字使用蓝灰色。
- 输入与按钮：输入区比面板略深；次级按钮使用深色描边；主按钮继续使用蓝色。
- 状态色：成功、警告、错误均使用深色背景配高亮文字，避免浅色大面积闪烁。
- 音频控件：通过 `color-scheme: dark` 使用浏览器原生深色控件。
- 代码、路径、历史记录、模型卡片、健康卡片、Toast、阶段进度条全部适配深色层级。

HTML 根节点写入 `data-theme="dark-console"`，用于稳定契约与后续定向扩展；本次不提供主题切换。

## 可读性与响应式

- 主文字与面板背景保持不低于常用 WCAG AA 的对比目标。
- 所有 focus-visible 状态保留清晰外框。
- 既有 1220/820/560 px 响应式断点不改变。
- 禁止残留白色表面背景，避免局部刺眼。

## 代码范围

- `src/voice_pipeline/webui/index.html`：删除 Logo，标记深色主题并更新缓存版本。
- `src/voice_pipeline/webui/styles.css`：替换全局变量与所有硬编码浅色表面。
- `tests/contract/test_workbench_api.py`：冻结无 Logo、深色主题和关键表面契约。

不修改 JavaScript、后端 API、数据库或推理流程。

## 验收

1. 页面中不再存在 `.brand-mark` 与“声”Logo。
2. 根节点标记 `dark-console`，CSS 声明 `color-scheme: dark`。
3. 顶栏、导航、章节工具栏、三栏工作台、设置页、系统状态页均无白色面板。
4. 输入框、按钮、状态标签、进度条、错误和成功状态可读。
5. 原生音频控件显示深色样式且时长功能不回归。
6. 桌面与窄屏布局无横向溢出。
